# 📦 NodeShare

**Share and discover knowledge** — Cross-platform node sharing application built with Java 21 + JavaFX.

---

## 🚀 Features

- ✅ **Real-time updates** — See new nodes instantly
- ✅ **Offline mode** — Access cached content without internet
- ✅ **File sharing** — Share PDFs, images, DOCX files
- ✅ **Cross-platform** — Windows EXE & Android APK
- ✅ **Dark/Light theme** — System-aware theming
- ✅ **Local storage** — SQLite for offline caching
